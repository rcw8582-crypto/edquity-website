# IEP Quality Short Form: Ten Indicators

Module 1 scoring instrument · Edquity at the Margins

Scores two sections of an IEP, present levels and annual goals. Five compliance indicators, five substantive indicators.

**Document reviewed:** ________________  **Reviewer:** ________________  **Date:** ________

## How to score

Mark each indicator Met or Not Met. Met scores 1, Not Met scores 0. There is no partial credit.

An indicator with several parts is met only when **all** parts are met.

An indicator that applies to every goal is met only when **every** goal satisfies it. A single goal missing the element leaves the indicator not met.

Write the evidence for your decision in the Notes column. Quote or cite the specific text in the document that supports it.

## Compliance indicators

| Indicator | Met | Not Met | Notes: evidence for your decision |
|---|---|---|---|
| **C1. Present levels reports assessment data for each area of need.** For every area of need described in present levels, the document must name the assessment, give the date it was administered, and report the score. All three parts are required for this indicator to be met. | ☐ | ☐ | |
| **C2. Present levels states how the disability affects progress in the general education curriculum.** The statement must describe this student in this curriculum. A statement that would apply equally to any student with the same eligibility category does not satisfy this indicator. | ☐ | ☐ | |
| **C3. Every goal states an observable skill and a target criterion.** The verb must be observable, such as solve, write, read, identify, or increase. The criterion must name the level the student is expected to reach. Both parts are required in every goal. | ☐ | ☐ | |
| **C4. Every goal states how progress is measured and when it is reported.** Each goal must name a measurement method and a reporting schedule. Both parts are required in every goal. Whether that method can actually be administered is scored separately at S4. | ☐ | ☐ | |
| **C5. Every area of need in present levels has an annual goal.** Read each need out of present levels, then match it to a goal. A single need without a corresponding goal leaves this indicator not met. | ☐ | ☐ | |

## Substantive indicators

| Indicator | Met | Not Met | Notes: evidence for your decision |
|---|---|---|---|
| **S1. Every goal states a quantified baseline.** The goal must state the baseline, and the baseline must be traceable to an assessment named in present levels. A baseline that appears only in present levels does not satisfy this indicator. | ☐ | ☐ | |
| **S2. Every goal's expected rate of improvement is appropriately ambitious.** Calculate the growth the goal asks for each week between baseline and target, then weigh that rate against the gap present levels describes. A target the student could reach without instruction does not satisfy this indicator. | ☐ | ☐ | |
| **S3. Every goal names the condition, setting, or materials.** Each goal must state what the student has access to while working on it. | ☐ | ☐ | |
| **S4. Every goal's measurement tool could be administered identically by any teacher.** The tool must name what it contains, how it is scored, and where it is given. Teacher observation, exit tickets, and teacher report do not satisfy this indicator. | ☐ | ☐ | |
| **S5. Present levels and goals pass the stranger test.** A teacher who has never met this student must be able to read these two sections and know what to teach on Monday. | ☐ | ☐ | |
